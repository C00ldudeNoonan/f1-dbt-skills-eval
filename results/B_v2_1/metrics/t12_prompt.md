Two questions from leadership, exactly as asked:

> "Which drivers actually overperform their car? I want a list I can trust."

> "Are pit stops really getting faster, or is that a myth?"

Build whatever models you think answer these well, then write up the answers. You decide the definitions. Document your assumptions, the data's limitations, and anywhere the question itself is misleading. Add tests where they make sense. Make sure `dbt build` succeeds when you're done.
